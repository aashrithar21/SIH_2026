# Government sources used to ground this prototype

This prototype is **not claiming that the generated 12,000 project rows are real government records**.

The training data is synthetic, but its schema and milestone-risk logic are grounded in official Government of India sources.

## 1. Department of Land Resources — LACRRIS

Official system:
https://larr.dolr.gov.in/

LACRRIS project-wise progress page:
https://larr.dolr.gov.in/faces/public/projectwise.xhtml

LACRRIS state/UT-wise progress:
https://larr.dolr.gov.in/faces/public/rptLandAcqProg2.xhtml

LACRRIS dashboard:
https://larr.dolr.gov.in/faces/common/dashboard.xhtml

Official data-entry / ranking-criteria PDF:
https://www.larr.dolr.gov.in/faces/pdf/Steps_of_data_entry.pdf

The LACRRIS public project-wise page defines fields including project name, acquisition statute,
land requiring body, district, rural/urban, land extent, timelines, land owners/PAFs,
SIA, preliminary notification, publication, awards, payment, possession,
compensation and R&R amounts.

The official LACRRIS ranking criteria document gives benchmark timelines for:
- SIA notification/submission
- SIA to preliminary notification
- land-record updating
- objection disposal
- acquisition-cost deposit
- preliminary notification to declaration
- award
- R&R implementation

These official thresholds are used to create the synthetic milestone data and benchmark-breach features.

## Important disclosure for SIH

The 12,000 rows generated by `src/generate_data.py` are synthetic prototype records.
They are NOT copied from or presented as actual government project records.

The correct production path is:
official departmental/project records -> data validation -> feature engineering -> model retraining.

For the SIH prototype, this gives a reproducible ML dataset while keeping the data model
and delay benchmarks grounded in Government of India land-acquisition systems.
